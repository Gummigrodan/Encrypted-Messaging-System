# Encrypted Messaging System

Made by Isac Larsson (2026-07-28)

## Why i built it

Recently goverments in the EU has approved a feature called Chat Control.
This allows an algorithm to scan messages in social media before they send.
This feature is good because it prevents grooming but also removes the concept 
of privacy. This EMS will encrypt messages before you send them making it harder
for the algorithm to scan the messages.

## How it works

The encryption works by creating a random array of numbers in the end of the message.
These numbers acts like instructions to the message which shuffles the message.
When you decrypt the message the program reads the numbers in the back of the message.

## A hidden feature

When i was bug testing the program i noticed that you could encrypt it multiple times and
it still would work. So if the users feels like using a deeper encryption they could tell the
reader to decrypt it multiple times.

## In the future

Im planning to make this project into an electronics device so you dont have to use monitored
apps to send the messages. Then to read the messages you would need the right Encryption software
AND a radio signal deciver with the right frequency.
